# frontend/

Aquí vivirá la PWA de BikePOS (React + TypeScript + Vite).

Se poblará a partir de la **Fase 2** del plan (esqueleto, base offline y prueba de impresión) y se construirá sobre ella el POS local-first desde la **Fase 6**.

Ver la estructura propuesta y el stack completo en el `README.md` de la raíz del repositorio y en `docs/decisions.md`.
