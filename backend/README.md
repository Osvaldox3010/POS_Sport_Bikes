# backend/

Aquí vivirá el backend de BikePOS: Java + Spring Boot, monolito modular (ver `docs/decisions.md`, ADR 002).

Se poblará a partir de la **Fase 2** del plan (esqueleto), con autenticación y auditoría base en la **Fase 3** (primer despliegue público).

Módulos previstos: `auth`, `users`, `catalog`, `inventory`, `sales`, `payments`, `returns`, `layaway`, `cash`, `price-approval`, `reports`, `settings`, `audit`, `sync`.
